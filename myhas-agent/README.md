# myhas.io

Secure remote access to your Home Assistant, with no open port and no
change to your router.

## Get started

1. Select **Start** above. Turn on **Start on boot**, **Watchdog** and
   **Show in sidebar** too.
2. Select **Open Web UI**, or **myhas.io** in the sidebar.
3. Follow the page. It shows each step: claim this Home Assistant with your
   myhas.io account, and let Home Assistant trust the agent (one click with
   **Fix it for me**).

The same page shows the status at any time: connected or not, the address
of your Home Assistant, for example `https://sunny-otter-4821.ha.myhas.io`,
and what to do if something is wrong.

You need a myhas.io account (by invitation). Manage your Home Assistant at
[portal.myhas.io](https://portal.myhas.io). The **Documentation** tab has
every step in detail.
